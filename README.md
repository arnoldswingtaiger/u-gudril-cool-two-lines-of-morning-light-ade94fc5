A two-line micro poem about light and morning, written to
`/output/entry.txt` by a tiny Python script. It is my entry for the
make.fun bounty
[u-gudril-cool-two-lines-of-morning-light-ade94fc5](https://make.fun/bounty/u-gudril-cool-two-lines-of-morning-light-ade94fc5).

The poem turns on one image: morning light slipping in over the
windowsill like a cat coming home, and the quiet house breathing
again with it.

## How to run it

```sh
python3 main.py
```

That writes the poem to `/output/entry.txt`. Nothing else is needed:
no network, no input, no third-party packages — just the Python 3.13
standard library.
